# Aira Browser

Версия 0.3.0.

Первый рабочий прототип настольного браузера со стеклянным интерфейсом. Внутри используется Chromium из Electron.

## Что уже работает

- вкладки и открытие ссылок в новой вкладке;
- адресная строка и поиск через DuckDuckGo;
- подсказки по открытым и недавно посещённым страницам;
- верхняя стеклянная полоса для перетаскивания окна;
- стартовая страница с симметричной сеткой до 10 редактируемых ярлыков;
- перетаскивание вкладок мышью и горячими клавишами;
- переходы назад и вперёд;
- обновление и остановка загрузки;
- горячие клавиши `Ctrl/Cmd + L`, `T`, `W`, `R`;
- сборка для Windows, macOS и Linux;
- изоляция загружаемых страниц от Node.js.

## Горячие клавиши

- `Cmd/Ctrl + W` — закрыть вкладку; если она последняя, закрыть окно Aira;
- `Cmd/Ctrl + R` — обновить страницу;
- `Cmd/Ctrl + T` — открыть новую вкладку;
- `Cmd/Ctrl + [` и `Cmd/Ctrl + ]` — назад и вперёд;
- `Control + Tab` — перейти к следующей вкладке;
- `Control + 1…9` — перейти к вкладке по номеру;
- `Cmd/Ctrl + Shift + ←/→` — передвинуть активную вкладку.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm start
```

## Создание установщика

Сборка выполняется для текущей операционной системы:

```bash
npm run dist
```

Результат появится в папке `release`.

## Важное ограничение прототипа

Запросы сайтов к камере, микрофону, геолокации и уведомлениям пока блокируются. Перед повседневным использованием браузеру также понадобятся интерфейс разрешений, менеджер загрузок, история, закладки, восстановление сессии и регулярные обновления Electron.
